# ДЗ 2. Текстовое ранжирование

Ник на Kaggle: `anastassiyatseluiko`

- Публичный nDCG@10 — 0.61270
- Локальный nDCG@10 на 200 отложенных запросах — 0.62682. Локальный TF-IDF — 0.61325

## Запуск

В активном окружении Python 3.12 установите зависимости и запустите скрипт:

```bash
python -m pip install -r requirements.txt
python solution.py --submission_file=submission.csv data
```

Папка `data` должна содержать `vkmarco-docs.tsv`, `vkmarco-doceval-queries.tsv` и `objects.csv`. Скрипт сохраняет `ObjectId,Score` для всех пар из `objects.csv` в исходном порядке. В Linux также можно запустить `./solution.py --submission_file=submission.csv data`.

## Формула

Заголовок, текст и запрос лемматизируются. IDF и средние длины полей считаются по всему корпусу. Для каждой пары вычисляется BM25 отдельно по заголовку и тексту. Используются `k1 = 1.2`, `b_title = 0.3`, `b_body = 0.75` и смесь `0.5 × BM25_title + BM25_body`. Смесь нормируется в пределах кандидатов каждого запроса.

К ней прибавляются бонусы из формулы, выбранной в эксперименте:

```text
score = normalized_field_mix
      + 0.4 * title_window + body_window
      + title_phrase + 0.05 * body_phrase
      + 0.05 * coverage
```

`window` — число различных слов запроса, делённое на длину кратчайшего окна с этими словами. Кратчайшее окно ищется через min-heap по спискам позиций. `phrase` — индикатор точного совпадения последовательности лемм. `coverage` — доля суммарного IDF слов запроса, найденных хотя бы в одном поле.

Параметры подобраны на 800 размеченных запросах. Метрика выше получена на остальных 200 запросах и относится к той же формуле в экспериментальной версии. Короткий скрипт использует фиксированные параметры. На контрольном наборе скоры совпали с экспериментальной реализацией. Для сверки с готовым сабмишном на полном корпусе запустите скрипт с отдельным именем выходного файла.

Исходные функции `read_queries`, `read_qrels` и `read_docs` сохранены из шаблона. Для большого корпуса основной запуск использует потоковое чтение и хранит частоты и бонусы для кандидатов.
