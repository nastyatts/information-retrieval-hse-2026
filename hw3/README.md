# ДЗ 3. Обучение ранжированию

- **Ник на Kaggle:** `anastassiyatseluiko`
- **Публичный nDCG@10 :** **0.62386**

## Решение

Используется LightGBM с функцией потерь LambdaRank. Модель обучается на всех 67 готовых признаках. Дополнительные признаки, внешние данные и ансамбли не используются. `QueryId` задаёт группы документов и не входит в признаки; `ObjectId` используется только для формирования сабмишна.

## Валидация и параметры

Обучающие данные делятся по запросам: 5 600 запросов для обучения и 1 400 для валидации. Документы одного запроса целиком попадают в одну часть. Seed разбиения и модели — `42`. Параметры подбирались только по обучающим данным.

Метрика — среднее nDCG@10 по запросам с gain `2**Label - 1`.

| Модель | nDCG@10 на валидации |
|---|---:|
| CatBoostRanker, YetiRank, 200 итераций (бейзлайн) | 0.623055 |
| LightGBM LambdaRank (итоговое решение) | 0.634298 |

Параметры итоговой модели:

| Параметр | Значение |
|---|---|
| `objective` | `lambdarank` |
| `metric` | `ndcg` |
| `ndcg_eval_at` | `[10]` |
| `label_gain` | `[0, 1, 3, 7]` |
| `lambdarank_truncation_level` | `13` |
| `learning_rate` | `0.03` |
| `num_leaves` | `15` |
| `min_data_in_leaf` | `50` |
| `lambda_l2` | `5.0` |
| `feature_fraction` | `0.9` |
| `seed` | `42` |
| `num_threads` | `4` |
| `deterministic` | `True` |
| `force_col_wise` | `True` |

Максимум — 2 000 итераций; ранняя остановка — после 150 итераций без улучшения nDCG@10 на валидации. Выбрано **942 дерева**. После этого модель заново обучается на всех 7 000 обучающих запросах с выбранным числом деревьев.

Дополнительная проверка с seed разбиения `2026` и фиксированными 942 деревьями: бейзлайн — **0.615647**, решение — **0.619361**. По этому разбиению параметры не подбирались.

## Запуск в Linux / WSL

Используется Python 3.12. Из папки с `solution.py` и `requirements.txt`:

```bash
python3.12 -m venv .venv-wsl
source .venv-wsl/bin/activate
python -m pip install -r requirements.txt
```

Обучение и сохранение модели:

```bash
python solution.py --train --model_file=model.bin PATH-TO-DATA
```

Загрузка модели и создание сабмишна:

```bash
python solution.py --model_file=model.bin --submission_file=submission.csv PATH-TO-DATA
```

`PATH-TO-DATA` — папка с `train.csv` и `test.csv`. Если данные лежат рядом с `solution.py`, укажите `.`.

Результат — файл `submission.csv` с колонками `ObjectId,Score`, по строке на каждый объект из `test.csv`. Более высокий `Score` означает более высокую позицию документа внутри запроса.

В проверочном окружении полное обучение заняло около 6 минут на CPU при пиковом потреблении памяти 622 МиБ; предсказание — около 1 секунды. GPU не требуется.
